# Linguae

Linguae is a React and TypeScript language-learning demo built with Vite, TanStack Router, and Tailwind CSS.

## Development

```sh
npm install
npm run dev
```

## Checks

```sh
npm run build
npm run lint
npm test
```

TanStack Router generates `src/routeTree.gen.ts` from the files in `src/routes`.
Learning and admin demo data are saved in the browser's local storage.
